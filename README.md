# Guilherme Apps

Umbrel community app store.

| App | Description |
|-----|-------------|
| GlitchTip (`gx-glitchtip`) | Sentry-compatible error tracking |
| Fleet (`gx-fleet`) | Device inventory and management over private Tailscale HTTPS |
| Dench (`gx-dench`) | CRM with agents and WhatsApp over private Tailscale HTTPS |
| Terminal (`gx-terminal`) | Root shell on the Umbrel host in the browser, behind the umbrelOS login |

Add it in umbrelOS under **App Store → ⋯ → Community App Stores** with the URL
`https://github.com/guilhermexp/umbrel-apps`.

Fleet packaging and validation: [gx-fleet/AGENTS.md](gx-fleet/AGENTS.md).
Dench packaging and validation: [gx-dench/AGENTS.md](gx-dench/AGENTS.md).
